# 🌟 Tech For Girls - Registration Website 💻✨

Welcome to the official **Tech For Girls - Registration Website**!  
This mini project is part of a community initiative to help girls learn practical web development skills, including form handling, file uploads, Google Sheets integration, and front-end interactivity. 🎯

---

## 📋 Features

✅ Clean, modern UI using HTML, CSS, and JavaScript  
✅ Registration form with:
- Name
- Phone number
- Email ID
- College / Department

✅ WhatsApp Sharing with Counter:
- Opens a pre-written message
- Tracks number of shares (5 required before form submission)

✅ File Upload Support (Screenshot/Resume/etc.)

✅ One-time Submission Enforcement:
- Form disables after submit
- Saved flag in browser `localStorage` to block multiple submissions

✅ Google Sheets Integration using Google Apps Script

✅ Success message after submission 🎉

---

## 🛠️ How It Works

1. User fills in all required form fields
2. Shares the invite on WhatsApp 5 times
3. Uploads a screenshot (e.g., resume or proof of sharing)
4. On submission:
   - Data is sent to a Google Sheet via Web App
   - Submission is blocked for future attempts (using `localStorage`)
